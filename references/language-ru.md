# Russian (ru)

Read this file when the session language is Russian. How the language is chosen is defined in `session-engine.md` (Language section), not here. This file only gives the Russian names and wording, so that every session uses the same terms.

The protocols themselves stay in the English technique files. Follow them step by step and say each prompt in natural Russian. Do not translate word for word.

---

## Address

Use «ты» by default, as the technique descriptions below do. If the user writes to you with «вы», switch to «вы» for the rest of the session.

---

## Technique names

Use these names when you recommend, list or name a technique. The command slugs (`thought-record`, `tipp` and so on) stay in English.

| Slug | Name in Russian | One-line description |
|---|---|---|
| `tipp` | **ТРУД** (TIPP, ДБТ) | Быстро снизить накал сильных эмоций с помощью телесных техник. |
| `opposite-action` | **Противоположное действие** (ДБТ) | Когда эмоция не соответствует фактам, сделать противоположное тому, к чему она побуждает. |
| `dear-man` | **ПОПРОСИ** (DEAR MAN, ДБТ) | Подготовиться к сложному разговору — сформулировать просьбу или отказ и отрепетировать, как это сказать. |
| `wise-mind` | **Мудрый разум** (ДБТ) | Когда трудно принять решение, прислушаться и к чувствам, и к доводам рассудка. |
| `chain-analysis` | **Анализ поведенческой цепочки** (ДБТ) | Разобрать поступок, о котором жалеешь, звено за звеном, чтобы понять, где в следующий раз можно прервать эту цепочку. |
| `thought-record` | **Дневник мыслей** (КПТ) | Шаг за шагом проверить мысль и разобраться, что делать, в том числе если она окажется верной. |
| `behavioral-activation` | **Поведенческая активация** (КПТ) | Когда настроение снижено, запланировать одно небольшое действие, которое имеет для тебя значение. |

Abbreviations: ДБТ — диалектическая поведенческая терапия, КПТ — когнитивно-поведенческая терапия. Say "техники из КПТ и ДБТ", never that the toolkit *is* therapy.

### Acronym letters

ТРУД and ПОПРОСИ are Russian acronyms for TIPP and DEAR MAN. The English files name a step by its letter (T — Temperature, D — Describe, and so on).

## Check-in

- Opening: «Что сейчас происходит? Пары предложений достаточно.»
- Intensity: «Насколько это сильно прямо сейчас, от 0 до 10, где 10 — максимум?»

## Safety message

The rules are in `session-engine.md` (Safety section) and apply unchanged. When they call for the crisis message in Russian, say it warmly and plainly, in your own words, and give the same contacts:

- экстренные службы: 112 (в ЕС) или местный номер экстренной помощи;
- Германия: Telefonseelsorge, 0800 111 0 111 (бесплатно, круглосуточно);
- другие страны: findahelpline.com.
